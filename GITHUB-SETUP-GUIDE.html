🚀 GitHub Pages Setup Guide

Follow these steps one by one. Click each step when done to track your progress.

⏳ Your Progress0 / 18 steps done
1🔥 Setup Firebase (Database)
✓
Open Firebase Console
Go to 👉 https://console.firebase.google.com
Sign in with your Google account.
✓
Create a New Project
Click "Add project" → Type any name like sudha-lic-website → Click Continue → Click Create project → Click Continue
✓
Register a Web App
On your project home page, click the </> icon → Type nickname my-website → Click Register app
✓
Copy your Firebase Config
You will see a box with code. Copy the entire firebaseConfig object — it has apiKey, authDomain, projectId etc.
✓
Paste Config into firebase-config.js
Open your firebase-config.js file in Notepad. Replace the placeholder values with your real values. Save the file.
apiKey: "AIzaSy...", authDomain: "your-project.firebaseapp.com", projectId: "your-project", storageBucket: "your-project.appspot.com", messagingSenderId: "123456789", appId: "1:123456789:web:abc"
✓
Enable Firestore Database
In Firebase Console → left menu → Firestore Database → Click Create database → Choose "Start in test mode" → Click Next → Click Enable
✓
Enable Firebase Storage
In Firebase Console → left menu → Storage → Click Get started → Choose "Start in test mode" → Click Done
2🐙 Create GitHub Account
✓
Go to GitHub and Sign Up
Open 👉 https://github.com → Click "Sign up" → Enter your email, password, username → Verify your email
✓
Sign In to GitHub
After creating account, click "Sign in" and enter your email and password.
3📁 Create a Repository
✓
Click "New Repository"
On GitHub home page, click the green "New" button on the left side, OR click the "+" icon at top right → "New repository"
✓
Fill in Repository Details
• Repository name: type cms-website
• Description: type anything like "My CMS Website"
• Select Public (important! Private won't work with free Pages)
• Leave everything else as default
• Click "Create repository"
4📤 Upload Your Files
✓
Click "uploading an existing file"
After creating the repository, you will see a page that says "Quick setup". Look for the link that says "uploading an existing file" and click it.
✓
Upload ALL files from cms-website folder
Drag and drop these files into the upload box:

✅ index.html
✅ products.html
✅ reviews.html
✅ firebase-config.js (with your config filled in!)
✅ README.md
✅ 404.html
⚠️ You cannot drag the "admin" folder directly. You need to upload admin files separately — see next step.
✓
Commit (save) the files
Scroll down on the upload page → You will see "Commit changes" section → Leave the message as default → Click the green "Commit changes" button
✓
Upload the admin folder files
In your repository, click "Add file" → "Upload files"

Open your admin folder on your computer. Drag ALL these files into the upload box:

✅ login.html
✅ dashboard.html
✅ upload.html
✅ news-manager.html
✅ schemes-manager.html
✅ products-manager.html
✅ reviews-manager.html
✅ style.css
⚠️ Important: After uploading, GitHub will put them in the ROOT folder. You need to move them into an "admin" subfolder. See next step.
✓
✅ EASIER METHOD — Use GitHub Desktop App
Instead of uploading files one by one, use GitHub Desktop — it uploads folders properly!

1. Download: https://desktop.github.com
2. Install and sign in with your GitHub account
3. Click "Clone a repository" → select your cms-website repo → choose a folder on your PC
4. Copy all your cms-website files into that folder
5. In GitHub Desktop → you will see all files listed → type a message like "Upload all files" → Click "Commit to main" → Click "Push origin"
6. Done! All files including the admin folder will be uploaded correctly!
5🌍 Enable GitHub Pages (Make it Live!)
✓
Go to Repository Settings
In your repository page, click the "Settings" tab at the top (it has a gear icon ⚙️)
✓
Find the Pages section
In Settings, scroll down on the left sidebar and click "Pages"
✓
Set Source to main branch
Under "Branch" section → click the dropdown that says "None" → select "main" → make sure folder is set to "/ (root)" → Click "Save"
✓
🎉 Your website is LIVE!
Wait 2-3 minutes → Refresh the Settings → Pages page

You will see a green box saying:
"Your site is live at https://YOUR-USERNAME.github.io/cms-website"

Click that link — your website is now live on the internet! 🎉
Your URL will be: https://YOUR-GITHUB-USERNAME.github.io/cms-website

🎉 All Steps Complete!

Your website should now be live on GitHub Pages! Share your URL with everyone.
